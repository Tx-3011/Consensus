# Demonstration Guide

Target length: about 2 minutes 45 seconds. Use a previously verified saved live investigation for replay and label it clearly. Replay must not dispatch provider, source, or model requests.

| Time | Demonstration |
|---|---|
| 0:00-0:20 | State the research question, selected surfaces, and the distinction between answer agreement and evidence independence. |
| 0:20-0:45 | Show the collected answers, claim groups, and raw citation count. |
| 0:45-1:25 | Select one claim, group shared evidence, and inspect the exact text and explicit relationship receipt. |
| 1:25-2:00 | In a separate live investigation, show the bounded Google Search follow-up and its budget receipt. Do not imply replay is live. |
| 2:00-2:25 | Compare before/after evidence accounting and explain whether the follow-up changed the finding. |
| 2:25-2:45 | Show unresolved evidence, source receipts, static export, and the practical value of avoiding a false consensus count. |

## Recording Checklist

- Verify the demonstrated relationship in the saved source text before recording.
- Include one contrasting claim with multiple independent roots.
- Avoid the illustrative "18 citations collapse into one source" statement unless a collected investigation actually establishes it.
- Ensure captions identify fixture versus live data and expand acronyms.
- Provide accurate spoken narration, edited captions, readable zoom, and sufficient pointer contrast.
- Test repository and video links in a private browser window.
- Do not display `.env`, API keys, authorization headers, or provider account pages.
